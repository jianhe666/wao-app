# 哇哦记账 · WAOO

哇哦记账是一款 **原生 Android、对话优先、本地优先** 的记账 App。

不用先选分类、再填表格。说一句「午饭 35，微信」，或者把支付截图丢进对话，就能记下一笔。它也可以自动读取支付通知，在后台把能抓到的账单记下来。

核心账目默认保存在手机本地。AI 和网盘备份是可选能力，需要时才会联网。

---

## 为什么叫「哇哦」

记账通常很琐碎。

哇哦记账想做的事很简单：让记账这件事轻一点，最好轻到一句话、一张截图，甚至什么都不用做。

> 哇哦一下，账就记好了。

先把每一笔花销记清楚。资产、负债和净值，是接下来的方向。

## 功能

### 对话记账

- 用自然语言记账，例如「午饭 35，微信」「昨天打车 26」
- 发支付截图，交给 AI 识别金额、商户、时间和账户
- 支持补充备注、修改分类和账户
- 支持收入、支出和转账

### 自动抓取

- 通过 Android 通知监听读取微信、支付宝等支付通知
- 可选无障碍增强，只读取支付结果页面文字
- 只处理支付结果，不截屏、不上传原始通知
- 抓取后可以在待确认列表里检查

> 自动抓取依赖通知权限和支付 App 是否发出通知，不能保证每一笔都成功。

### 账单导入

- 导入微信、支付宝账单
- 支持 CSV、XLSX
- 自动去重，导入后可以继续修正分类

### 流水与筛选

- 按月查看收入、支出和结余
- 按支出/收入筛选
- 分类支持多选
- 按时间、金额、首字母排序
- 支持正序、倒序
- 搜索商户和备注

### 分类

- 内置餐饮、购物、交通、居住、娱乐、医疗等分类
- 支持自定义分类
- 自定义分类排在普通分类之后
- 「其他」永远排在最后
- 分类选择器用加号新增分类

### 统计

- 分类支出环形图
- 每日支出柱状图
- 账户支出堆叠条和占比
- 常去的店按消费次数排序
- 排除美团、拼多多等线上消费
- 合并「微信支付-星巴克」「支付宝-星巴克」这类支付平台前缀造成的同名店

### AI 智能分类 Beta

- 选择最近一天、一周、一月或全部账单
- 逐笔判断分类，不按商户一刀切
- 分类没有变化时不打扰用户
- 用户确认过的「商户 + 备注」会本地记录，之后同类账单直接复用
- 分类记录可以逐个修改
- 已处理过的账单不会重复送去 AI
- 支持单笔取消、全部取消和批量确认

> AI 分类需要自己配置 OpenAI 兼容 API Key。功能仍标记为 Beta。

### 重复账单合并

自动抓取记录和 AI 对话/手动记录满足以下条件时，会提示合并：

- 金额相同
- 收支方向相同
- 时间相差 10 分钟以内

由用户决定合并还是保留两笔，不会自动删除。

### 报销

- 给支出标记报销状态
- 记录报销金额和到账情况
- 统计里区分已报销和未报销

### 数据与备份

- 账目默认保存在本机
- 支持导出/恢复 JSON 备份
- 支持导出 CSV
- 可选百度网盘自动备份
- 升级或更换手机时可以恢复账目

---

## 隐私

- 核心记账功能不需要联网
- 不默认上传原始支付通知
- AI 分类只发送商户、备注和收支方向，不发送金额、订单号或原始通知
- AI API Key 只保存在本机
- 百度网盘 AppKey、SecretKey 和 token 只保存在本机，不写入备份
- Android 系统云备份默认关闭

## 技术栈

- Kotlin
- Jetpack Compose + Material 3
- Navigation Compose
- MVVM + StateFlow
- Room
- DataStore
- WorkManager
- NotificationListenerService
- 可选 AccessibilityService
- OpenAI 兼容 API

最低支持 Android 8.0（API 26），目标 Android 15（API 35）。
